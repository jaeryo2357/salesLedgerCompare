# 엑셀 매입자료 비교 웹사이트

두 파일을 선택하면 **브라우저 안에서만** 비교하고, 각 원본의 셀 위치와 값을 유지한 결과 `.xlsx` 파일 2개를 다운로드합니다. B 결과 파일에는 노랑·빨강 표시가, A 결과 파일에는 파랑 표시가 적용됩니다.

## Render 배포

1. Render에서 **New → Blueprint**를 선택하고 이 저장소를 연결합니다.
2. `render.yaml`의 Static Site 설정을 확인하고 배포합니다.
4. 생성된 `onrender.com` 주소를 사용합니다.

Render는 정적 HTML·CSS·JavaScript 파일만 제공하며 엑셀 파일을 받지 않습니다. 엑셀 비교와 결과 생성은 사용자의 브라우저 메모리에서 이루어집니다.

## 사업자번호 기준 비교

1. 먼저 각 파일의 헤더명으로 비교할 시트·열·데이터 시작 행을 자동으로 찾습니다. 제목 행 수가 달라도 처리할 수 있습니다.
2. A와 B를 사업자번호별로 그룹화합니다. 날짜와 행 순서는 비교 기준에 포함하지 않습니다.
3. 각 사업자번호 그룹이 A와 B에 같은 수의 행으로 존재하는지 확인합니다. B에 대응하는 A 행이 없으면 빨강으로 표시합니다.
4. 같은 사업자번호 그룹에서 금액이 같은 행을 먼저 1:1 대응합니다. 남은 행은 공급가액 차이가 1,000원 미만일 때만 같은 계산서로 추정해 노랑으로 표시합니다. 1,000원 이상 차이나면 다른 계산서로 보고 빨강으로 표시하며, 1,000원 미만 후보가 여러 개여서 행을 고를 수 없을 때도 빨강으로 표시합니다.
5. B의 전자세금계산서는 사업자번호·공급가액을 필수로 찾고, 세액 헤더는 선택 사항입니다. 세액 열이 없는 전자계산서 목록은 면세 문서로 처리하며 A의 `면세` 행과만 비교합니다.
6. B에 세액 열이 있는 전자세금계산서는 A의 면세 행과 비교하지 않습니다. A의 `불공` 행은 공급가액과 부가세(세액)가 모두 같아야 대응되고, A의 그 외 비면세 행은 공급가액만 비교합니다.
7. 공급가액 차이가 1,000원 미만이거나 불공 행의 세액이 실제로 다를 때 해당 B 셀을 노랑으로 표시합니다. B에 대응하는 A 행이 없거나, 공급가액 차이가 1,000원 이상이거나, 대응 관계가 모호하면 해당 B 행의 공급가액 셀 하나를 빨강으로 표시합니다.
8. B에 대응하는 A 행이 확실히 없으면 A 결과 파일에서 해당 행의 공급가액 셀을 파랑으로 표시합니다. B 결과 파일에는 B 원본 시트만 유지됩니다.

## 화면의 행별 판정 내역

비교가 끝나면 결과 요약 아래에서 검토가 필요한 행을 먼저 확인할 수 있습니다. 각 항목에는 사업자번호, 원본 행 번호, 문서 유형, A/B 공급가액·세액과 판정 근거를 표시합니다. 같은 사업자번호에 여러 행이 남아 임의로 연결할 수 없는 경우에는 후보 행 수와 함께 `대응 관계 모호`로 설명합니다. `전체 N건 보기`를 누르면 정상 일치 행까지 모두 확인할 수 있습니다.
