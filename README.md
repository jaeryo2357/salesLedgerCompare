# 엑셀 매입자료 비교 웹사이트

두 파일을 선택하면 **브라우저 안에서만** 비교하고, B 전자세금계산서 파일의 셀 위치와 값을 유지한 `.xlsx` 결과를 다운로드합니다.

## Render 배포

1. Render에서 **New → Blueprint**를 선택하고 이 저장소를 연결합니다.
2. `render.yaml`의 Static Site 설정을 확인하고 배포합니다.
4. 생성된 `onrender.com` 주소를 사용합니다.

Render는 정적 HTML·CSS·JavaScript 파일만 제공하며 엑셀 파일을 받지 않습니다. 엑셀 비교와 결과 생성은 사용자의 브라우저 메모리에서 이루어집니다.

## 사업자번호 기준 비교

1. 먼저 A와 B를 사업자번호별로 그룹화합니다. 사업자번호가 비교의 유일한 매칭 기준입니다.
2. 각 사업자번호가 A와 B에 같은 수의 행으로 존재하는지 확인합니다. B에 대응하는 A 행이 없으면 빨강으로 표시합니다.
3. 같은 사업자번호가 여러 행이면 각 파일에서 나타난 순서대로 1:1 대응합니다. 공급가액·부가세·날짜를 대응 행을 찾는 키로 사용하지 않습니다.
4. 대응된 행의 비교 대상 값이 실제로 다를 때만 노랑으로 표시합니다. 값이 같으면 색을 칠하지 않습니다.
