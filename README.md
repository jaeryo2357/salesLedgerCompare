# 엑셀 매입자료 비교 웹사이트

두 파일을 선택하면 **브라우저 안에서만** 비교하고, B 전자세금계산서 파일의 셀 위치와 값을 유지한 `.xlsx` 결과를 다운로드합니다.

## Render 배포

1. Render에서 **New → Blueprint**를 선택하고 이 저장소를 연결합니다.
2. `render.yaml`의 Static Site 설정을 확인하고 배포합니다.
4. 생성된 `onrender.com` 주소를 사용합니다.

Render는 정적 HTML·CSS·JavaScript 파일만 제공하며 엑셀 파일을 받지 않습니다. 엑셀 비교와 결과 생성은 사용자의 브라우저 메모리에서 이루어집니다.

## 사업자번호 기준 비교

1. 먼저 각 파일의 헤더명으로 비교할 시트·열·데이터 시작 행을 자동으로 찾습니다. 제목 행 수가 달라도 처리할 수 있습니다.
2. A와 B를 사업자번호와 날짜별로 그룹화합니다. 행 순서는 비교 기준에 포함하지 않습니다.
3. 각 사업자번호·날짜 그룹이 A와 B에 같은 수의 행으로 존재하는지 확인합니다. B에 대응하는 A 행이 없으면 빨강으로 표시합니다.
4. 같은 사업자번호·날짜 그룹에서 공급가액이 같은 행을 먼저 1:1 대응합니다. 남은 행이 A/B 각각 한 건씩일 때만 금액 차이를 비교하고, 여러 행이 남아 대응 관계가 모호하면 B 행을 빨강으로 표시합니다.
5. B의 전자세금계산서는 사업자번호·공급가액을 필수로 찾고, 세액 헤더는 선택 사항입니다. 세액 열이 없는 전자계산서 목록은 면세 문서로 처리하며 A의 `면세` 행과만 비교합니다.
6. B에 세액 열이 있는 전자세금계산서는 A의 면세 행과 비교하지 않습니다. A의 `불공` 행은 공급가액과 부가세(세액)가 모두 같아야 대응되고, A의 그 외 비면세 행은 공급가액만 비교합니다.
7. 공급가액 또는 불공 행의 세액이 실제로 다를 때만 해당 B 셀을 노랑으로 표시합니다. B에 대응하는 A 행이 없으면 사업자번호·공급가액·세액 셀을 빨강으로 표시합니다.
